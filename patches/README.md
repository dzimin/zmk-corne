# Исправление ZMK v0.2

Основа: `zmkfirmware/zmk@241ff39556b3685c9344c4c22fd9a655af8eb3ba` (v0.2), закреплена в `config/west.yml`

`0001-zmk-split-battery-disconnect-guard.patch` — проверенный патч из независимого аудита от 2026-11-03. Он устраняет запись за границы массива батарей на центральном устройстве при отключении BLE-хоста, который не является split-половинкой. Проверяется принадлежность соединения слоту и граница индекса при извлечении события из очереди

Это исправление памяти, а не подтверждённое исправление разряда физически правой половинки. Настройки сна, питания, радио и раскладка не изменены. Дефекты EXT_POWER из аудита в этот патч не входят

## Применение

После `west update`, перед `west build`:

```sh
python3 scripts/apply_zmk_patches.py /path/to/west-workspace/zmk
```

Скрипт проверяет HEAD ZMK, хеш патча, исходный и полученный `central.c`. Повторное применение допускается только при полном совпадении с проверенным результатом. Неожиданные изменения останавливают сборку

Workflow `build-firmware.yml` — локальная адаптация reusable workflow того же коммита ZMK. Она добавляет применение патча и сохранение диагностических артефактов; лицензия upstream находится в `LICENSE.zmk`. Внешний workflow без этого шага использовать нельзя: один manifest не применяет патч

## Проверка

```sh
python3 tests/test_zmk_ble_disconnect.py \
  --zmk-root /path/to/unpatched/zmk \
  --patch patches/0001-zmk-split-battery-disconnect-guard.patch \
  --output-dir /tmp/corne-ble-test
```

Тест взят из независимого аудита; удалён только несовместимый с macOS флаг линковщика `-no-pie`. Настоящие функции ZMK извлекаются из исходника; очередь, BLE и планировщик заменены заглушками. Проверяются восемь ожидаемых исходов: отключение слотов 0/1, чужого host-соединения и ошибочное событие перед корректным — до и после патча. Ошибка исходной версии должна воспроизводиться под UBSan; исправленная версия должна пройти все сценарии

Слоты 0/1 не обозначают физические L/R. Эти тесты не заменяют компиляцию всех целей или проверку на устройствах
